# Hamza Murad — Portfolio

Static copy of the hamzamurad.com website (pre-built Next.js output).

## Run locally

```bash
npx serve -l 3000
```

Then open http://localhost:3000.

## Deploy on Vercel

Import this repo, set **Framework Preset** to **Other**, leave the build command empty and the output directory as the root, then deploy.

Note: this is compiled output, not the original source code. The page content is in `index.html`.
